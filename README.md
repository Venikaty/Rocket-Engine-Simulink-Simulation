# 🚀 Basic Rocket Engine Simulation in Simulink

This project models a basic rocket engine using MATLAB & Simulink as part of
the Propulsion Lab at KIIT University.

## Features
- Thrust equation: F = m_dot*Ve + (Pe - Pa)*Ae
- Mass flow rate = 20 kg/s
- Altitude, velocity, propellant depletion simulation
- Atmospheric pressure decay with altitude

## How to Run
1. Open rocket_engine_model.slx in Simulink.
2. Run rocket_parameters.m.
3. Click Run Simulation (solver: ode45, 60s).
